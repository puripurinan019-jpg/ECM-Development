# ECM LTD. (บริษัท อี.ซี.เอ็ม ดีเวลลอปเม้นท์ จำกัด) Website

เว็บไซต์ทางการสำหรับ บริษัท อี.ซี.เอ็ม ดีเวลลอปเม้นท์ จำกัด (E.C.M. DEVELOPMENT LTD.) ผู้นำด้านการผลิต ประกอบ และขนส่งสลิงอุตสาหกรรม ลวดสลิง โซ่ยก สลิงผ้าใบ สลิงกลม และอุปกรณ์ยกตามขนาด (มม.) และความยาว (เมตร)

---

## 📁 โครงสร้างโปรเจกต์
- index.html - หน้าหลักของเว็บไซต์ (มีทั้ง 4 หน้า: หน้าแรก, เกี่ยวกับเรา, สินค้า, ติดต่อเรา พร้อมระบบสลับหน้าและ Modal อธิบายเพิ่มเติม)
- bout.html - ลิงก์ตรงหน้าเกี่ยวกับเรา
- products.html - ลิงก์ตรงหน้าสินค้า 8 รายการ
- contact.html - ลิงก์ตรงหน้าติดต่อเรา
- ssets/css/styles.css - สไตล์และการตกแต่งธีมสีขาว-น้ำเงินเนวี
- ssets/js/main.js - ข้อมูลสินค้า 8 รายการ, ตาราง WLL, เครื่องมือคำนวณสเปกสลิง และระบบ Modal
- ssets/images/ - ไฟล์รูปภาพตัวอย่างและโลโก้ SVG พร้อมให้เปลี่ยนเป็นรูปถ่ายจริงได้ทันที
